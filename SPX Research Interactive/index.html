RESEARCH NOTES

What each line represents

Options only, with SPX, or both

Options use 100% of current equity in SPX notional at each option roll. “With SPX” adds 100% SPX price exposure to that same option strategy. All quantities stay fixed between rolls, then resize using the combined portfolio’s equity. SPX stays invested when an option trade is unavailable. This is an overlay, not a 50/50 portfolio.

Dates and option expiries are separate

The expiry filter chooses the option’s holding schedule. Date controls choose which part of the historical portfolio you view. Changing dates does not restart trades or reselect hedges. Returns include the first selected session, using the prior close as the starting value (or initial capital on the first research date). Every line is rebased to the same starting capital.

Buffers buy protection; Sharpe does not select them

Buffers use the full allocated net credit on every traded roll. The rule chooses the closest affordable target to the money, preferring a 5-point width at that target and allowing 4 or 3. At least one buffer per short contract is required; the remaining budget buys more of it. Actual width is at least 3% of entry SPX. If no valid buffer is affordable, the option combination stays in cash. Targets use the existing one-point grid, with hedge strikes between 80% and 100% of SPX.

Long-put selections are retrospective

Long-put combinations retain the earlier highest full-period combined Sharpe selections. They are historical research winners, not out-of-sample results. Adding SPX or changing the visible dates does not optimize or change those selected hedges.

Costs, returns and metrics

Each option leg pays 25% of its full bid/ask spread from midpoint plus $1.50 per contract at entry. Positions settle at intrinsic value on expiry; daily marks use the audited quotes. SPX excludes dividends. Cash earns zero. Financing, borrowing costs and taxes are not included.

CAGR uses elapsed calendar years. Volatility and Sharpe use daily returns, annualized at 252 sessions; Sharpe assumes a zero cash rate. Drawdown starts with the selected period’s starting capital in its high-water mark. Annualized statistics are unavailable for a single session. Short windows can produce extreme annualized values.
